# Lesson 25: Enterprise GitHub capstone

## Goal
Deliver a complete governed GitHub operating model.

## Required deliverables
1. Enterprise and organization architecture
2. Identity and access matrix
3. Repository governance standard
4. Ruleset and required-check baseline
5. Secure CI/CD promotion model
6. Supply-chain policy
7. Security and compliance playbook
8. Migration runbook
9. Backup and recovery exercise
10. Metrics and a 90-day adoption plan

# লেসন ০২: Git-এর মানসিক মডেল

**লক্ষ্য:** কমান্ড মুখস্থ নয়, Git ভেতরে কী করে বুঝে ফেলা। বাকি সব লেসন এর ওপর দাঁড়িয়ে।

## ১. Git ≠ GitHub
- **Git:** আপনার কম্পিউটারে চলা ভার্সন-কন্ট্রোল টুল (ডিস্ট্রিবিউটেড)। ইন্টারনেট ছাড়াই কাজ করে।
- **GitHub:** Git রিপোজিটরি হোস্ট করার সার্ভিস + PR, Issues, Actions ইত্যাদি অতিরিক্ত ফিচার। (বিকল্প: GitLab, Bitbucket)

## ২. তিনটি এলাকা (সবচেয়ে গুরুত্বপূর্ণ ছবি)
```
Working Directory  ──git add──▶  Staging Area (Index)  ──git commit──▶  Repository (.git)
 (আপনার ফাইল)                    (পরের কমিটে যা যাবে)                  (সংরক্ষিত ইতিহাস)
        ◀──────────────── git restore / git switch ◀──────────────────────
```
- `git status` বলে কোন ফাইল কোন এলাকায়।
- Staging থাকার কারণ: একই সময়ের পরিবর্তন থেকে **বেছে নিয়ে** আলাদা আলাদা অর্থপূর্ণ কমিট বানানো।

## ৩. কমিট = স্ন্যাপশট (পার্থক্য নয়)
- প্রতিটি কমিট প্রজেক্টের সেই মুহূর্তের **পূর্ণ স্ন্যাপশট** + মেটাডেটা (লেখক, তারিখ, বার্তা) + **parent কমিটের লিংক**।
- একটা SHA-১ হ্যাশ (যেমন `c6a9f79`) দিয়ে পরিচয়: কন্টেন্ট বদলালে হ্যাশ বদলায়। তাই "কমিট বদলানো" আসলে নতুন কমিট বানানো।
- ইতিহাস = কমিটের একটা গ্রাফ (DAG): প্রতিটি কমিট parent-এর দিকে ইশারা করে।

## ৪. ব্রাঞ্চ, HEAD, ট্যাগ: সবই শুধু "লেবেল"
- **ব্রাঞ্চ** = একটা কমিটের দিকে ছোট সচল পয়েন্টার (৪১ বাইটের ফাইল)। নতুন কমিট হলে পয়েন্টার এগোয়।
- **HEAD** = "আমি এখন কোথায়": সাধারণত একটা ব্রাঞ্চের দিকে।
- **ট্যাগ** = একটা কমিটের দিকে **স্থির** লেবেল (রিলিজ চিহ্নিত করতে)।
- তাই ব্রাঞ্চ বানানো ও মোছা প্রায় বিনামূল্যে এবং নিরাপদ: কমিটগুলো মুছে যায় না (reflog-এ থাকে, লেসন ০৮)।

```
main:    A ── B ── C          (main → C)
                    \
feature:             D ── E   (feature → E, HEAD → feature)
```

## ৫. রিমোট ও ট্র্যাকিং ব্রাঞ্চ
- **remote** = অন্য জায়গার রিপো (সাধারণত `origin` = GitHub)।
- `origin/main` = **আপনার লোকালে রাখা শেষ-জানা অবস্থার কপি**, সরাসরি রিমোট নয়। `git fetch` এটা হালনাগাদ করে।

## ৬. আপনার রিপোতেই দেখুন
```bash
git log --oneline --graph --all
git status
git branch -vv
ls .git            # HEAD, config, objects, refs
cat .git/HEAD      # ref: refs/heads/main
cat .git/refs/heads/main   # main-এর কমিট হ্যাশ
git cat-file -p HEAD       # কমিট অবজেক্টের ভেতরটা
```
(প্রতিটি কমান্ড পড়ার-জন্য, কিছু বদলায় না ✅।)

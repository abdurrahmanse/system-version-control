# AI-র উত্তর নিজে যাচাই করুন (৫ মিনিটের চেকলিস্ট)

AI ভুল করতে পারে। বিশ্বাস করার আগে যাচাই করুন:

1. **কমান্ড আছে কি?** `git help <cmd>` বা `git <cmd> -h` খুলে ফ্ল্যাগটা দেখুন। `gh <cmd> --help` একইভাবে।
2. **ভার্সন মিলছে কি?** `git --version`, `gh --version`, `node -v`, `pnpm -v`। প্যাকেজ: `package.json`।
3. **ডক খুলুন:** git-scm.com/docs/<cmd>, docs.github.com। UI-র পথ (Settings → …) বদলাতে পারে।
4. **ঝুঁকিপূর্ণ হলে আগে স্যান্ডবক্সে** চালান। ডিফল্ট ধরুন: `git status` ও `git log --oneline --graph --all` দিয়ে আগে-পরে তুলনা।
5. **dry-run:** `git clean -n`, `git push --dry-run`, `git merge --no-commit --no-ff`।
6. **AI-কে ফাঁদে ফেলে পরীক্ষা করুন:** একটা বানোয়াট ফ্ল্যাগ (`git commit --auto-magic`) সম্পর্কে জিজ্ঞাসা করুন। ভালো উত্তর: "এমন ফ্ল্যাগ নেই"।
7. **দুই উৎসে মেলান:** AI + অফিশিয়াল ডক। না মিললে ডক জেতে।

## লাল পতাকা 🚩
- উৎস/লিংক ছাড়া অতিরিক্ত আত্মবিশ্বাসী উত্তর
- `--force`, `reset --hard`, `--no-verify`-এর "কুইক ফিক্স"
- একটাই পদ্ধতিকে "একমাত্র সঠিক" বলা (merge বনাম rebase)
- আপনার ভার্সনে নেই এমন ফিচার

# Git ও GitHub কারিকুলাম: জিরো থেকে প্রো ম্যাক্স

> পুরো প্রজেক্টটাই **Version Control শেখার জন্য**: এই ডক, ওয়েবসাইট (`pnpm dev`), প্র্যাকটিস-রিপো আর AI মেন্টর একসাথে একটা শেখার ব্যবস্থা। সম্পূর্ণ পথ: **[ROADMAP.md](ROADMAP.md)**।

## কীভাবে শিখবেন
1. **একটা একটা লেসন, ক্রমানুসারে।** [PROGRESS.md](PROGRESS.md) খুলে টিক দিয়ে এগোন।
2. **নিজের হাতে টাইপ করুন।** কপি-পেস্ট করলেও আগে কমান্ডের মানে পড়ুন। AI-কে কমান্ড চালাতে বলবেন না (AI মেন্টর শুধু ব্যাখ্যা করে)।
3. **প্রতিটি লেসনে তিনটা জিনিস:** ধারণা → কমান্ড → প্রজেক্টে অনুশীলন → চেকপয়েন্ট।
4. **ভুল করুন নিরাপদে।** ঝুঁকিপূর্ণ কমান্ড (reset, rebase, force push) আগে **স্যান্ডবক্স রিপোতে** প্র্যাকটিস করুন ([লেসন ০৮](lessons/08-undo.md)-এ বানানো হবে)।
5. **আটকে গেলে** `git status` আগে দেখুন, তারপর `git help <কমান্ড>`, তারপর AI মেন্টরকে আপনার আউটপুটসহ জিজ্ঞাসা করুন।
